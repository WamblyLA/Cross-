## Первый показ кода

На момент первого показа кода была создана базовая структура проекта

В репозитории подготовлены основные папки будущего проекта:
- /frontend - десктоп версия на Electron + React
- /backend - серверная часть на Node.js 
- /mobile - мобильная версия на React Native + Expo

Также начата реализация базового функционала и проработка архитектуры приложения: реализованы сценарии авторизации, хранения проектов и их редактирования, визуальные настройки<br>
Таким образом, было зафиксировано начало работы
